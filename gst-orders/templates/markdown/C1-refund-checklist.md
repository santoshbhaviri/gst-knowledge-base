# Refund Processing Checklist (updated, October 2026)

> **How to use this checklist.** Fill one copy for every refund application and keep it in the file with the order. Mark each line **Y** (done, in order), **N** (done, problem found: give details in Remarks) or **NA** (not applicable to this category). Part A applies to every claim. Part D has one block for each category; use only the block for this claim. **Who fills what:** the Range fills Parts A, C, D and E as its verification report, naming in Remarks the portal or record checked (back office, ADVAIT, GST Prime, DIGIT, ICEGATE, SEZ Online, e-way bill portal); the proper officer fills Parts B, F, G and H. This checklist updates the zone's refund checklist of 18.07.2025 with the CGST Rules as amended up to Notification No. 13/2025-Central Tax, Instruction No. 06/2025-GST and the lessons from the refund orders reviewed in 2026.

| Stage | Time limit | Provision |
