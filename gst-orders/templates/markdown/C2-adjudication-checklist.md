# Checklist C2: Adjudication checklist, one page per stage (SCN, hearing, order, after the order)

> **How to use this checklist.** Print one copy for each SCN and keep it on the file. Tick each box only when the step is done and the proof is on the file; if a line does not apply, write "NA" beside the box. Any unticked line points to the provision or case that explains the risk: fix it before moving to the next stage. Built from the court-proof checklist (gst-law/adjudication/03-court-proof-checklist.md). Cases are marked SC (binding on all), TG (Telangana High Court, binding here) or P (persuasive). Case entries in the project files are secondary; read the judgment before quoting it.
