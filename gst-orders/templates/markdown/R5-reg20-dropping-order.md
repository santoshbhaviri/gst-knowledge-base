# Template R5: Order dropping cancellation proceedings and revoking suspension (FORM GST REG-20, rule 22(4) and rule 21A(4))

> **How to use this template.** Use it when (A) the reply to a REG-17 or REG-31 is satisfactory; (B) a non-filer has filed **all** pending returns and paid tax, interest and late fee, in which case dropping is **mandatory** (proviso to rule 22(4)); (C) a rule 10A defaulter has furnished valid bank details; or (D) you are prima facie satisfied with a REG-31 reply and want to revoke the suspension while verification continues (Circular No. 145/01/2021-GST para 5.4). Keep the one option that applies. Copy the reason line into the portal REG-20 and attach this order. Delete every "Drafting note" before issue.
