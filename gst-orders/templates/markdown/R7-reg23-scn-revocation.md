# Template R7: Show cause notice for rejection of an application for revocation of cancellation (FORM GST REG-23, rule 23(3))

> **How to use this template.** Rule 23(3) and the proviso to section 30(2) forbid rejecting a revocation application without this notice and a hearing. Issue it only after checking the points in the table in para 2. If everything is in order, **revoke by REG-22 (template R8, Part A)** within thirty days of the application instead. Since 10.07.2024 the proper officer for section 30 and rule 23 is the **Superintendent** (Circular No. 223/17/2024-GST). Where the application has been filed under a High Court direction after the portal limit (Telangana HC *KBG Associates*, W.P. 23897/2026; *Check Security Force*, W.P. 22632/2026; *Adarsha Transport*, W.P. 31578/2026), do **not** propose rejection on limitation alone; decide the conditions on merits within the court's time. Delete every "Drafting note" before issue.
