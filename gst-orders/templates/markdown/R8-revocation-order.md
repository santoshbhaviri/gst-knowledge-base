# Template R8: Order on an application for revocation of cancellation: Part A revocation (FORM GST REG-22) and Part B rejection (FORM GST REG-05) (rule 23(2))

> **How to use this template.** **Part A** revokes the cancellation (REG-22) within **thirty days** of the application. Rule 23(2)(a) requires satisfaction "for reasons to be recorded in writing", which the portal REG-22 ("found to be in order") does not show, so attach this order. **Part B** rejects the application (REG-05) only after a REG-23 notice and hearing (template R7), within thirty days of the REG-24 reply (rule 23(4)). Keep only the part needed. Where the application was filed under a High Court direction, say so in para 1 and decide within the court's time. Delete every "Drafting note" before issue.
