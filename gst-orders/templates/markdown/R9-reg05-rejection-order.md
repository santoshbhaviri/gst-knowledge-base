# Template R9: Order rejecting an application for registration, amendment or cancellation, or a rule 14A withdrawal (FORM GST REG-05, rules 9(4), 19(4) and 14A)

> **How to use this template.** Use it only after a REG-03 (template R1) and only when the reply did not cure a point in it, or no reply came by the date given. The portal REG-05 has a short reason box; attach this order and copy a one-line reason into the box. Time: within **seven working days** of the REG-04 reply, or of the last date for reply (Instruction No. 03/2025-GST para 8(vii)-(viii)). Courts set aside REG-05 orders that give no reasons or rely on documents not given to the applicant (Bombay HC *Om Impex*, 2024), and refusals of a new registration where the officer's findings on an earlier cancellation appear only in a later affidavit (Patna HC *Maharaj Ji Enterprises*, 2025). For a revocation application, use template R8 Part B instead. Delete every "Drafting note" before issue.
