> **How to use this template.** Use it for a **new registration** application (Part A), an **amendment** application (Part B) or a **cancellation or rule 14A withdrawal** application (Part C). Keep only the part you need. Upload the text in the REG-03 reason box on the back office, or attach this letter to it. Time limits: new registration, **7 working days** from submission (**30 days** where the applicant is flagged risky after Aadhaar authentication, has not authenticated Aadhaar, or verification has been approved by the AC under rule 9(1) proviso (b)); amendment, **15 working days** from the REG-14. Every query must fall under one of the four grounds allowed by **Instruction No. 03/2025-GST para 8(v)**. Ask only for documents in the REG-01 list (para 6). For any other document, first obtain the approval of the Deputy/Assistant Commissioner (para 8(vi)) and record it in the drafting note below. Delete every "Drafting note" before issue.

**Part C: Cancellation application (REG-16) or withdrawal from rule 14A (REG-32)**

**2. Points to be clarified**

> **Drafting note.** For REG-16, Circular No. 69/43/2018-GST para 5 allows a query **only** where (a) the application is incomplete, or (b) in a transfer, merger or amalgamation, the transferee is not registered. Otherwise the application must be accepted within thirty days from the date sought. For REG-32, check rule 14A(5) and (6): returns for at least one tax period (applications from 01.04.2026), all returns due up to the application, no section 29 proceedings, and particulars amended first.
